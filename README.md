# Password Strength Checker

A real-time password strength checker built with vanilla HTML, CSS, and JS. It uses regex to score password complexity on the fly.

## How it works
The script scores the password from 1 to 5 based on:
* Length (Minimum 8 characters)
* Lowercase letters
* Uppercase letters
* Numbers
* Special characters

The UI meter dynamically updates its width and color (red to green) based on the score.

* **Logic & HTML:** Hand-coded HTML and JavaScript logic.
* **Styling:** AI generated only the CSS styleout.
